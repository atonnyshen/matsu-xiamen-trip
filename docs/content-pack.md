## 2. 設計系統（Open Design：warm-editorial）

色票：背景 `#FAF7F2`／前景 `#1C1A17`／赤陶 `#C0512F`／森林綠 `#2F5B4F`／暖灰 `#8A817A`／白 `#FFFFFF`／延伸海洋藍 `#145DA0`・深海 `#0B3C5D`・琥珀 `#B36A1F`
字型：標題 GT Sectra／Noto Serif TC；內文 Söhne／system-ui
佈局：1200px、Hero 72vh（checklist 40vh）、section 72px、圓角 12–16px、無多餘陰影

> 設計系統選擇說明（2026-08-11 複驗）：比較 Open Design 全庫 130+ 設計系統後，warm-editorial（serif 主導的雜誌美學、赤陶點綴暖紙白）仍是最符合「人文之旅」氣質的方案——storytelling/paper/vintage 等替代皆為通用 token 風格，缺乏 warm-editorial 的編輯感與留白哲學，維持現案並以「增加內容深度」而非「換膚」強化。

## 8. IP 地域分流＋語言轉換技術說明（v10.1 核心・v11 不變）

### 原理
1. 頁面載入時讀 `localStorage('matsu-region')`：`'tw'/'cn'` 直接套用；`'auto'`（或無）→ 呼叫 `https://ipapi.co/json/`（CORS、5 秒 AbortController timeout）取得 `country_code`
2. `CN` → 大陸模式；其他/失敗 → 台灣模式（預設）
3. 模式切換只改 `<html data-region>`，CSS `[data-region="cn"] .region-tw { display:none }` 處理顯示
4. 手動按鈕循環 `tw → cn → auto`（`__cycleRegion`），切換後 reload 以載入正確語言版本

### 語言轉換
- **字元映射 T2S**：500+ 繁→簡字元對（內嵌、離線可用，無外部依賴）
- **詞彙映射 TW2CN**：40+ 台灣慣用語→大陸慣用語
- **轉換範圍**：全部 text nodes＋頁面標題＋QUOTES 引文全文（13 篇）
- **品質**：350+ 高頻繁字殘留掃描＝零殘留

### 分流內容
| 資源 | 台灣/海外（tw） | 大陸（cn） |
|---|---|---|
| 語言 | 繁體中文（zh-Hant） | 簡體中文（zh-CN） |
| 地圖 iframe | Google Maps embed | 高德地圖卡片（uri.amap.com 連結） |
| 16 個地圖點 | Google Maps 連結 | 高德 URI 連結 |
| 音樂 | YouTube 直連 | 網易雲搜尋／Bilibili（南音） |
| 訂房/高鐵 | Trip.com 台灣版 | 不變（Trip.com 通用） |

### 已知限制（誠實說明）
- ipapi.co 在大陸可能被擋：5 秒 timeout 後 fallback 台灣模式，訪客可手動切換
- 分流是「建議」不是「保證」——VPN/漫遊會改變 IP 判斷，手動按鈕是終極手段
- 簡繁轉換為字形＋慣用詞層級，文學引文轉換後仍忠於原文（僅字形變換）
